Get running in a minute

  1. Download the exe and put it anywhere — there's no install step.
  2. Launch it and open a folder from the top bar.
  3. Press Ctrl+Tab for a shell, then run your agent of choice inside it.

04 First run

SmartScreen will complain

The v0.8 build is not code-signed, so Windows shows an "unrecognised app" prompt the first time you launch it. That is expected for an unsigned preview, not a sign that anything is wrong with the file — and the hash check above is how you confirm that.

Signed builds are on the roadmap and will remove the prompt. Until then, choose More info then Run anyway, or verify the SHA-256 first and decide from there.
